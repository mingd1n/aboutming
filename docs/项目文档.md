# 项目文档

> 本文件是网站的设计蓝图（目标 / 站点地图 / 需求 / 技术栈 / 里程碑）。
> 写法说明：每个关键决策给「初始样板」+「> 备注：你还可以选…」，后续逐步把占位符 `<...>` 填实。

## 1. 项目概述

- **定位**：简历主页 + 知识笔记的混合展示站。
- **语言**：全站中英文双语（i18n），所有页面与内容都要有中文 / 英文两个版本。
- **一句话**：丁铭（Axel / Ming）的个人站——展示简历方向、学习笔记与社交入口，面向招聘方 / 合作方 / 同好。
- **目标**：
  - [x] 展示个人简历与作品，用于求职 / 合作（M1 骨架已上线，细节持续补）
  - [ ] 沉淀并展示 Web3 / AI / 跨境电商等领域的学习笔记
  - [ ] 建立个人品牌（社交矩阵聚合）

## 2. 目标用户

- 招聘方 / HR（看简历与方向）
- 合作方（看项目与作品）
- 圈内同好（看笔记内容）
- 自己（内容存档与回顾）

## 3. 站点地图

> 依据 `Axel/Ming.md` 的内容树映射为网页结构。

```
/ → /zh/
├─ /zh | /en                 首页（Ming.md 简介 + 事业五方向）
├─ /zh/resume | /en/resume   简历总览（简历-Ming.md + 事业方向）
│   ├─ /resume/web3          ← Axel/sections/事业/web3
│   ├─ /resume/ai-dev        ← Axel/sections/事业/ai-dev
│   ├─ /resume/media         ← Axel/sections/事业/自媒体
│   ├─ /resume/ecommerce     ← Axel/sections/事业/跨境电商
│   └─ /resume/tourguide     ← Axel/sections/事业/TourGuide
├─ /zh/notes | /en/notes     笔记分类（对齐 vault 学习目录）
└─ /zh/contact | /en/contact 联系（简历-Ming + README 社交）
```

> 内容规则：展示名与结构以当前 `Axel/` 为准；vault 为空的简历不编造经历；不展示电话。

## 5. 技术选型

- **框架**：Astro + React Islands
- **3D**：Three.js（用于个人作品集部分，待有作品后启用）
- **UI**：Tailwind CSS v4（shadcn-ui 可按需后加）
- **动效**：Framer Motion / GSAP（M3）
- **内容渲染**：MDX（笔记，M2）
- **部署**：Vercel
