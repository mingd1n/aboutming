## 5. 技术选型（已定 · 2026-08-18）

| 项 | 选择 | 原因 |
| --- | --- | --- |
| 框架 | **Next.js App Router + React** | 主人未学 Astro；每个路由对应 `app/.../page.tsx`，好找；客户端组件适合动态壁纸 |
| 不用 | Astro | 已否决（难找页、偏静态） |
| UI | Tailwind CSS v4 | 与广州 Solarpunk 设计一致 |
| 动效 / 壁纸 | Framer Motion + `"use client"` 壁纸组件 | 动态背景、主题日城/夜城 |
| 内容 | `scripts/sync-content.mjs` → `data/generated.json` | 只读 Axel，构建/dev 前同步 |
| 部署 | Vercel | Next.js 原生友好 |

### 5.1 动态壁纸怎么做（实现指引，未开工）

1. **壳**：`app/[lang]/layout.tsx` 里放固定底层 `<Wallpaper />`，内容层 `z-index` 更高。
2. **组件**：`components/Wallpaper.tsx` 标 `"use client"`，可随主题切换日城/夜城。
3. **无视频时**：CSS 渐变 + 淡网格/电路呼吸（广州 Solarpunk）；不造假街景图。
4. **有素材时**：`materials/` 里视频或图序 → 拷到 `public/media/wallpaper.*`，壁纸组件改为 `<video muted loop playsInline>` 或淡入轮播；注意性能与 `prefers-reduced-motion`。
5. **不要**：一上来上 Three.js 全屏粒子当壁纸（重、且无作品时空洞）。

> 来源：主人 Figma 前提供的高保真视觉概念稿（本文件第 1 节「视觉一句话」）。代码按此实现。

- **首页 = 单页全宽纵向滚动**，非传统作品集；4 个编号章节各占一个全视口面板，每章内部横向滑动滚轴式（scroll-snap）。
- **左侧常驻纵向导航栏**：4 个编号章节——`01 WHAT I'M BUILDING 我在做` · `02 WHAT I'M THINKING 我在想` · `03 MY PLAN 我的计划` · `04 MY WORLD 我的世界`。用细竖线、小圆点指示器、微型进度标记、编号导航；当前章节用发光小圆点 / 高亮标记。
- **右侧极淡滚动进度条**：0% / 25% / 50% / 75% / 100%，克制优雅。
- **主视觉语言**：每个章节一块大抽象艺术（当代数字艺术，非商业插画）——层叠半透明形、建筑几何、有机形态、微妙渐变、玻璃质感、纸纹颗粒、柔光、细线图、抽象技术图解、破碎几何、植物元素、漂浮物、景深、留白。
- **禁止**：过量霓虹、赛博朋克、发光蓝/紫 AI 味、过量 3D、卡通插画、城市摄影/天际线/地标。
- **配色**：克制——深炭/近黑、暖白、柔灰、鼠尾草绿（muted forest green）、低饱和青（desaturated teal）、琥珀（subtle amber）、暖米色（warm beige）；琥珀/奶油作小面积点缀，不用高饱和。
- **字体**：现代无衬线；大标题优雅克制；小写英文大写标签 + 小号中文副题（例：`WHAT I'M BUILDING` / `我在做的事`）；小写标签宽字距；大标题 / 技术元数据 / 极小额导航三层对比。
- **Header（极简）**：左上 `MING / AXEL`（下 `BUILDER / EXPLORER`）；右上 `EN / 中` + 太阳/月亮线描图标（语言 + 主题）。
- **英文站**：UI 完整英文，结构跟中文；vault 长笔记不硬翻，英文页加原文说明。
- **章节内容（对齐 Axel 板块）**：
  - 01 我在做：五方向（web3 · ai-dev · 自媒体 · 跨境 · TourGuide）→ `/career/[direction]`；抽象「建造/系统/创意」视觉，迷你项目标记模块（AI DEVELOPMENT / WEB3 / FULL-STACK / PERSONAL PROJECTS），信息融入画面，不做传统项目卡片。
  - 02 我在想：**仅三个话题标签**（播客 · 文章 · 思维）→ 独立子页 `/learn/[topic]`。标签为大卡片（线描图标 + 大编号 + hover 放缩上浮 + 琥珀光晕）。话题归属写死在 `data/learn.ts`，不做 frontmatter 标签聚合。
  - 03 我的计划：极简时间轴/路径/坐标/进度指示/检查点；`NOW` / `NEXT` / `LATER`（vault 空则「建设中」占位，主人后补）。
  - **页首关于我**：头像 + Ming.md/`site.ts` 简介（不放教育行），在四章之前。
  - 04 我的世界：音乐 · 电影 · 旅行；**镜头 · GUANGZHOU** 仅城市图。**旅行不是 TourGuide**。章内不放 CONNECT。
- **Footer（极简）**：`MING / AXEL` `GUANGZHOU, CHINA` · `CONTACT ME →` · GitHub / Instagram / TikTok / 小红书 / 公众号（无 X）。联系入口只保留页脚。
- **04 章收束**：**不要**再放 `WHAT I'M BUILDING`，也**不要**放 CONNECT 块；联系只走页脚 `CONTACT ME`。
- **滚动**：文档单一滚动；禁止首页内层 `h-screen` 容器与外层 Footer 双滚动。
- **动效**：慢、电影感、有意；滚动时图层不同速度轻微视差、文字淡入滑入、导航指示更新、章节平滑过渡；避免花哨动画。
- **响应式**：移动端导航收成顶部/侧边紧凑指示器，保留编号章节系统与大抽象视觉，不简单堆叠桌面卡片。
