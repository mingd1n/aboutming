# 项目文档

> 本文件是网站的设计蓝图（目标 / 站点地图 / 需求 / 技术栈 / 里程碑）。
> 写法说明：每个关键决策给「初始样板」+「> 备注：你还可以选…」，后续逐步把占位符 `<...>` 填实。

## 1. 项目概述

- **定位**：简历主页 + 知识笔记的混合展示站。
- **语言**：全站中英文双语（i18n），所有页面与内容都要有中文 / 英文两个版本。
- **一句话**：<填这里：你是谁、展示什么、给谁看>
- **目标**：
  - [ ] 展示个人简历与作品，用于求职 / 合作
  - [ ] 沉淀并展示 Web3 / AI / 跨境电商等领域的学习笔记
  - [ ] 建立个人品牌（社交矩阵聚合）

## 2. 目标用户

- 招聘方 / HR（看简历与方向）
- 合作方（看项目与作品）
- 圈内同好（看笔记内容）
- 自己（内容存档与回顾）

## 3. 站点地图

> 依据 `Axel/Ming.md` 的内容树映射为网页结构。

```
首页（个人简介 + 导航）
├─ 简历
│   ├─ AI 应用 / AI 开发
│   ├─ Web3
│   ├─ 运营 · 创作 · 摄影
│   ├─ 跨境电商
│   └─ TourGuide（入境游）
├─ 笔记 / 文章
│   ├─ Web3（Web3 总览、Web3 Concepts、Bitcoin、ETH）
│   ├─ AI 开发（学习路线、基础概念）
│   └─ 跨境电商（工作流、ClimaCore）
└─ 联系 / 社交矩阵
```

> 备注：页面颗粒度可再议——简历四方向是「单页滚动」还是「独立页」；笔记是「按板块列表」还是「全文页」。

## 4. 功能需求

### P0（第一版必须）
- 静态展示：首页、简历、笔记列表
- 响应式布局（移动端适配）
- 暗色 / 亮色模式
- 导航与页面间跳转
- 社交账号链接
- 中 / 英双语框架（i18n 基础）

### P1（重要）
- 笔记 / 文章渲染（Markdown / MDX）
- 站内搜索
- 中 / 英内容双语完善（全部页面与笔记）

### P2（锦上添花）
- 首屏动效 / 3D 背景
- 页面转场动画
- RSS / 订阅

## 5. 技术选型

- **框架**：Astro + React Islands
  > 备注：内容 / 笔记友好、加载快；交互部分用 React 组件（Islands）实现。
- **3D**：Three.js（用于个人作品集部分，待有作品后启用）
  > 备注：可在 React 中用 React Three Fiber 简化写法。
- **UI**：Tailwind CSS v4 / shadcn-ui
  > 备注：也可用 UnoCSS、Chakra UI、纯 CSS。
- **动效**：Framer Motion
  > 备注：可选 GSAP。
- **内容渲染**：MDX（笔记）
  > 备注：也可用统一从 Obsidian vault 导出的脚本。
- **部署**：Vercel
  > 备注：也可选 Cloudflare Pages、GitHub Pages。
