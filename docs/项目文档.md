- **目标**：
  - [x] 展示个人简历与作品，用于求职 / 合作（M1 骨架已上线，细节持续补）
  - [ ] 沉淀并展示 Web3 / AI / 跨境等领域的学习笔记
  - [ ] 建立个人品牌（社交矩阵聚合）

### 长期内容规则

- **我在想**：从 `Axel/sections/学习思考/` 收录要公开的个人想法，接受一句话或长篇。来源可以是播客、文章、社媒或自己思考，网站统一展示正文，省略来源分类和旧索引。保留 Obsidian 的内部分类。时间轴按文件创建时间倒序，文件创建时间未提供时用已有日期；每张卡片可进入完整笔记。
- **方向页**：以对应 Obsidian 入口笔记为导航。前置正文、标题层级、链接及其出现顺序一并同步；学习路线、作品、笔记按原文组织，不由网页重建目录。正文的内部链接转站内页，显式反链保留入口，笔记页可回到所属方向。
- **我的目标**：从 `Axel/sections/兴趣/我的目标.md` 读取。这里留给主人记录想体验、想去的地方或个人愿望；当前没有内容时仅保留标题。旧「计划」不自动迁入。摄影作品在最底部，暂用简单换行网格。

### 8.1 首页「视觉 OS」当前设计

> 来源：主人 Figma 前提供的高保真视觉概念稿（本文件第 1 节「视觉一句话」）。代码按此实现。

- **首页三章**：01 我在做、02 我在想、03 我的世界。桌面左侧常驻目录，手机底部常驻目录，指针连续反映纵向滚动进度。
- **主视觉语言**：每个章节一块大抽象艺术（当代数字艺术，非商业插画）——层叠半透明形、建筑几何、有机形态、微妙渐变、玻璃质感、纸纹颗粒、柔光、细线图、抽象技术图解、破碎几何、植物元素、漂浮物、景深、留白。
- **禁止**：过量霓虹、赛博朋克、发光蓝/紫 AI 味、过量 3D、卡通插画、城市摄影/天际线/地标。
- **配色**：克制——深炭/近黑、暖白、柔灰、鼠尾草绿（muted forest green）、低饱和青（desaturated teal）、琥珀（subtle amber）、暖米色（warm beige）；琥珀/奶油作小面积点缀，不用高饱和。
- **字体**：现代无衬线；大标题优雅克制；小写英文大写标签 + 小号中文副题（例：`WHAT I'M BUILDING` / `我在做的事`）；小写标签宽字距；大标题 / 技术元数据 / 极小额导航三层对比。
- **Header（极简）**：左上 `MING / AXEL`（下 `BUILDER / EXPLORER`）；右上 `EN / 中` + 太阳/月亮线描图标（语言 + 主题）。
- **章节布局**：关于我在页首。五方向是换行网格。想法时间轴紧凑，内容溢出时可横滑。我的世界从旅行开始，以摄影网格收尾。普通按钮和可点击卡片统一用柔和圆角。
- **Footer（极简）**：`MING / AXEL` `GUANGZHOU, CHINA` · `CONTACT ME →` · GitHub / Instagram / TikTok / 小红书 / 公众号（无 X）。联系入口只保留页脚。
- **滚动**：文档单一纵向滚动。背景光带、点阵与章节线稿不同速移动，想法轨道仅在有内容可横滑时使用滚轮。
