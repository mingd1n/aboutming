# 项目文档

> 本文件是网站的设计蓝图（目标 / 站点地图 / 需求 / 技术栈 / 里程碑）。
> 写法说明：每个关键决策给「初始样板」+「> 备注：你还可以选…」，后续逐步把占位符 `<...>` 填实。

## 1. 项目概述

- **定位**：简历主页 + 知识笔记的混合展示站。
- **语言**：全站中英文双语（i18n），所有页面与内容都要有中文 / 英文两个版本。
- **一句话**：丁铭（Axel）的个人网站——用「计划 / 学习思考 / 事业」三条线串联简历、学习笔记与作品，展示一个正在成为超级个体的 21 岁广州青年的探索轨迹。
- **目标**：
  - [ ] 展示个人简历与作品，用于求职 / 合作
  - [ ] 沉淀并展示 Web3 / AI / 跨境电商等领域的学习笔记
  - [ ] 建立个人品牌（社交矩阵聚合）

## 2. 目标用户

- 招聘方 / HR（看简历与方向）
- 合作方（看项目与作品）
- 圈内同好（看笔记内容）
- 自己（内容存档与回顾）

## 3. 站点地图

> 依据 `Axel/Ming.md` 的内容树映射为网页结构（已定稿）。

### 内容树（Axel 源）

```
Ming.md（首页根节点）
├─ sections/计划/计划 → 每日计划
├─ sections/学习思考/学习 → 英语 / 阅读 / 播客 / 电影 / 学习方法
└─ sections/事业/事业
   ├─ web3 → web3简历 / web3学习（总览·Concepts·Bitcoin·ETH）/ 产出
   ├─ ai-dev → 学习路线图 / 学习（AI基础概念·开发基础概念）/ 产出（程序）
   ├─ 自媒体 → 摄影博主 / 科技博主 / AI视频（各含学习·产出）
   ├─ 跨境电商 → 简历 / 学习（工作流）/ 产出（ClimaCore）
   └─ TourGuide → 简历（入境游体验师）/ 城市探索计划模板
```

### 核心模式

`事业` 五个方向共享同一套「简历 / 学习 / 产出」三段式链条：

| 方向 | 简历（求职） | 学习（笔记） | 产出（作品） |
|------|-------------|-------------|-------------|
| Web3 | ✅ 有内容 | ✅ 4 篇 | ⚪ 空 |
| AI 开发 | ⚪ 空 | ✅ 路线图 + 2 篇 | ⚪ 链接未建 |
| 自媒体 | ⚪ 空 | ⚪ 空 | ✅ 摄影·科技账号 |
| 跨境电商 | ⚪ 空 | ✅ 工作流 | ✅ ClimaCore |
| TourGuide | ✅ 详 | — | ✅ 探索模板 |

每个页面底部均有 `← [[上级]]` 反链 → 导航需「面包屑向上 + 链接向下」。

### 页面结构（已定稿）

```

/plan 计划              每日计划清单

  /career/web3           Tab：简历(✅) · 笔记(4篇) · 产出(建设中)
  /career/ai             Tab：学习路线图 · 笔记(2篇) · 简历+产出(建设中)
  /career/media          Tab：摄影(✅) · 科技(✅) · AI视频(建设中)
  /career/ecommerce      Tab：学习工作流(✅) · ClimaCore(✅) · 简历(建设中)
  /career/tourguide      简历(✅详) + 城市探索模板
/contact 联系            社交账号矩阵聚合
```

### 已定决策

- 事业五方向：**每方向一个聚合页**，Tab 切换「简历 / 学习 / 产出」三段。
- 空占位笔记：**全部展示**，渲染为「建设中」占位页（不隐藏）。
- i18n：先搭框架，界面双语，笔记正文暂按中文原文，英文后续补充。
- 内容同步：构建时脚本从 `Axel/` 导出（见 AGENTS.md）。

## 4. 功能需求

### P0（第一版必须）
- 静态展示：首页、简历、笔记列表
- 响应式布局（移动端适配）
- 暗色 / 亮色模式
- 导航与页面间跳转
- 社交账号链接
- 中 / 英双语框架（i18n 基础）

### P1（重要）
- 笔记 / 文章渲染（Markdown / MDX）
- 站内搜索
- 中 / 英内容双语完善（全部页面与笔记）

### P2（锦上添花）
- 首屏动效 / 3D 背景
- 页面转场动画
- RSS / 订阅

## 5. 技术选型

- **框架**：Astro + React Islands
  > 备注：内容 / 笔记友好、加载快；交互部分用 React 组件（Islands）实现。
- **3D**：Three.js（用于个人作品集部分，待有作品后启用）
  > 备注：可在 React 中用 React Three Fiber 简化写法。
- **UI**：Tailwind CSS v4 / shadcn-ui
  > 备注：也可用 UnoCSS、Chakra UI、纯 CSS。
- **动效**：Framer Motion
  > 备注：可选 GSAP。
- **内容渲染**：构建时脚本从 vault 导出 Markdown（`scripts/sync-content.ts`）
  > 备注：也可用 MDX 直接渲染，或手动维护网站版内容；已定采用脚本导出。
- **部署**：Vercel
  > 备注：也可选 Cloudflare Pages、GitHub Pages。
