## 开发 / Development

技术栈：**Next.js（App Router）+ React** + Tailwind CSS v4 + Framer Motion。全站中英双语；内容从 `Axel/` 同步（`scripts/sync-content.mjs`）。首页为单页滚动「视觉 OS」4 章。

```bash
cd ~/Desktop/aboutming
npm install
npm run dev      # http://localhost:3000  → 自动跳到 /zh
npm run build
npm start        # 预览生产构建
```
