# 素材库

Finder：桌面 → `aboutming` → `materials`  
完整路径：`/Users/mingd1n/Desktop/aboutming/materials/`

往这里丢图片、切图、二维码和链接。  
这是工作台，不是 `Axel/`（笔记仍只写 vault）。网站真正引用的文件，实现时会拷到 `public/media/`。

## 丢哪里

| 文件夹 | 放什么 | 建议文件名 |
| --- | --- | --- |
| `portrait/` | 头像 / 半身照 1 张 | `axel.jpg` |
| `city/night/` | 广州或深圳夜景 3–6 张 | `gz-night-01.jpg` … |
| `city/day/` | 日景 2–3 张 | `gz-day-01.jpg` … |
| `photography/` | `minslens_` 作品 4–8 张 | `photo-01.jpg` … |
| `marks/` | 五方向线描，同等大小 | `ai-dev.svg` `media.svg` `web3.svg` `ecommerce.svg` `tourguide.svg` |
| `social/` | 公众号二维码等 | `wechat-oa.png` |
| `brand/` | favicon、OG 分享图 | `favicon.svg` `og-1200x630.png` |
| `figma/` | 画面导出 PNG、SVG 切图 | 与帧同名，如 `home-dark.png` |

规格：头像方图 ≥1200px；城市横图 ≥2000px 宽；切图 2x。优先自己拍，偏暖色。不要网图赛博城、AI 假脸。

超大原片（`.raw` `.tif` `.psd` `.fig`）可以放进来，但已被 gitignore，不会进仓库。
